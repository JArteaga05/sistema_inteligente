SISTEMA DE VEHÍCULOS INTELIGENTES - VERSIÓN WEB

Esta versión permite abrir el ejercicio directamente en un navegador.
No requiere instalar Python ni servidor.

PASOS:
1. Extrae el ZIP.
2. Abre la carpeta Sistema_Vehiculos_Web.
3. Haz doble clic en index.html.
4. Se abrirá en tu navegador predeterminado.

También puedes abrir la carpeta desde Visual Studio Code y hacer clic
derecho sobre index.html > Open with Live Server, si tienes esa extensión.

NOTA ACADÉMICA:
Esta versión web implementa las clases en JavaScript para que el navegador
pueda ejecutar la simulación. El proyecto original en Python sigue siendo
válido y se ejecuta con: python main.py.
